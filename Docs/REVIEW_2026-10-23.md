## 2. Checked, no change needed

- **Streak**: `StreakCounter.Reset` in `StartMatch`. `Record` runs once per round card (voids never reach it). The ON A
  ROLL flash ends at the next `SetRound` / `SetRoundLabel`, including `PRACTICE`. Rattled banter only plays when the
  opponent is host-acted.
- **Kill punch**: `killPunchPending` is set only for the opponent's kill and cleared in `StartMatch`, `Stop`,
  `EnterReview` and now `TutorialStage`. Reduced Motion: no flash and no kick.
- **NEW BEST / all-time best**: `SubmitBest` only for non-injected shots, so auto-tap and `SimulateSwipe` are
  `InputSource.Injected`. The tutorial never submits. The review `roundresult ... newbest` uses sample values and never
  writes.
- **Help sign colour** resets on every `SetCueMode`. **Settings replay** is only reachable from the title, and
  `OnTutorialThenTitle` goes through `ShowTitle`, which runs `Stop` and `CancelTutorial`.
- **Double subscriptions**: `panel.OnStreakTag` / `OnNewBest`, `cues.OnHeartBeat` and `ecg.OnBeat` are assigned once
  with `=`.
- **Per-frame allocations**: none in the new Update / Tick paths. Strings are built only on step changes (marked
  `alloc-ok`). `SetText` / `MarkDirty` / `Color` writes are behind step guards (`ApplySignColor`, `ApplyFlashColor`,
  `ApplyWaitLabel`, `TutorialCard.Place`). The timer's `SetChars` marks dirty only on change.
- **Timing**: the tutorial uses the match's own path (`PollCue(frameStart, PresentLatencyNs)`, `DuelClient.Press`).
  `PresentDraw(cuePresentedNs)` passes the same value it used to read. Nothing in the town, outcome or tutorial code
  writes the clock, reports or schedule.
